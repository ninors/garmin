Synchroniser avec Garmin

Pour lancer l'extraction automatique depuis votre compte Garmin Connect :

  1. Rendez-vous dans l'onglet Actions de votre dépôt GitHub.
  2. Cliquez sur le workflow Garmin Sync & Export.
  3. Cliquez sur le bouton Run workflow.

Astuce : Le workflow tourne également automatiquement tous les dimanches et sur chaque mise à jour du dépôt !
